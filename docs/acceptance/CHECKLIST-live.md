## 2. Курсор — досягаемость и точность

- [ ] Курсор двигается за указательным пальцем, направление не инвертировано (зеркальность)
- [ ] **Центр кадра → центр экрана**: палец в центре превью — курсор в центре экрана
- [ ] Правый край зелёного прямоугольника → правый край экрана

- [ ] Верх зелёного прямоугольника → верх экрана (до меню/строки заголовка)

- [ ] При этом рука целиком (или почти) остаётся в кадре и не теряется на краях
