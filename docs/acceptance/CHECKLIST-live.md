## Прогон 2 — что проверить (после коммита правок)

Отдельно, по пунктам:

1. **Низ достижим**: палец на нижней границе зелёной зоны → курсор на таскбаре; кисть при этом видна целиком (`Track: ok` в оверлее).
2. **Верх и центр не съехали**: центр зелёной зоны → центр экрана; верхняя граница → строка меню. Зона стала ниже по вертикали — это ожидаемо.
3. **Чувствительность по вертикали**: если вертикаль дрожит — уменьшай `cursor.overscan_y` к 2.0; если низ снова недостижим — увеличивай к 3.0. `cursor.overscan_y: 1.5` возвращает прежнее поведение (низ недостижим).
4. **Ложные клики**: те же ~2 минуты спокойного POINT + отдельно убрать руку из кадра 5–10 раз. Ожидание: 0 кликов. Если клик всё же есть — сверь `Track:` в оверлее в момент клика.
5. **DRAG при уходе руки**: зажать, начать тащить, убрать руку из кадра → окно бросается, кнопка не остаётся зажатой.
6. **Резкий бросок**: резко бросить руку через экран → курсор успевает, ложного PINCH/клика нет.
7. **Лицо**: навести камеру на лицо без руки в кадре → `Track:` должен показать `no hand` (или `low confidence`/`implausible hand size`), курсор не должен ходить. Если лицо всё ещё проходит — усиливай гейт: `tracking.min_hand_score` 0.6 → 0.7 и/или `hand.min_hand_detection_confidence` 0.65 → 0.7. Если наоборот пропала настоящая рука — ослабляй в обратную сторону.
8. **Обычные клики не пострадали**: пинч → клик с первого раза, удержание → DRAG.
9. **Незакрытые вопросы прогона 1**: `wheel_step: 300` — не слишком быстро? рабочее значение вместо 300? `volume.step: 0.04` — комфортно? Сколько времени до привыкания? Что раздражает больше всего? Что первым хочется закоммитить?
